# Guia Prático FaceZen

| Arquivo | Para quê |
|---|---|
| `FaceZen-Aulas-NotebookLM.pdf` | **Todas as aulas** (os 15 exercícios essenciais com desenho e cada tema de skincare), cada uma com o prompt para o NotebookLM. Gerado do app com `npm run aulas` |
| `FaceZen-Guia-Pratico.pdf` | O guia completo diagramado (para ler, vender ou subir no NotebookLM) |
| `FaceZen-Guia-Pratico-COMPLETO.md` | O mesmo guia em texto, fácil de editar |
| `modulos/01…09` | O guia dividido por tema: suba estes arquivos no NotebookLM e selecione só as fontes de cada vídeo |
| `10-roteiros-notebooklm.md` | Lista dos 14 vídeos, fontes de cada um e os prompts de personalização |

Conteúdo escrito com base em quatro materiais de referência (yoga facial e skincare), reescrito com linguagem própria e ajustado às regras de segurança do FaceZen.
